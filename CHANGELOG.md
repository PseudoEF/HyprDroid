- Добавлен официальный Gradle Wrapper 8.9 для Unix и Windows с проверкой SHA-256 дистрибутива.
- Исправлена установка Android SDK в CI: удалённый пакет `tools` заменён явным набором необходимых пакетов.
- GitHub Actions собирает debug APK через Wrapper и публикует `HyprDroid-debug-apk` на 14 дней; отсутствие APK считается ошибкой.
- Сборка и публикация artifact подтверждены [запуском для коммита 64d83e1](https://github.com/PseudoEF/HyprDroid/actions/runs/43699829017). Проверка установки и работы на устройстве остаётся открытой.
- Обновлена публичная документация: разделены текущие возможности и планы, описаны установка, сборка и ограничения Android. Правила AI-разработки вынесены в постоянные технические инструкции AGENTS.md.

## 0.1.0 — начальный прототип

Обозначение версии в исходниках; отдельный опубликованный релиз не подтверждён.

- Базовая структура HOME-лаунчера на Kotlin и Jetpack Compose.
- Три рабочих пространства с общим списком приложений и переключателем Grid/List.
- Получение списка доступных приложений и вызов запуска по нажатию.
- Первоначальный workflow GitHub Actions для debug APK.
