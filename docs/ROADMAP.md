# Дорожная карта

Отмеченные пункты реализованы в исходниках или подтверждены указанной проверкой. Проверка поведения на устройстве учитывается отдельно от сборки. Порядок этапов отражает направление развития; сроки не установлены.

## Этап 0 — базовый прототип и сборка

- [x] HOME activity на Kotlin и Jetpack Compose.
- [x] Получение списка доступных приложений текущего профиля и вызов запуска по нажатию.
- [x] Три перелистываемых рабочих пространства с общим набором приложений.
- [x] Переключатель Grid/List для плиток.
- [x] Gradle Wrapper 8.9 с проверкой SHA-256 дистрибутива.
- [x] GitHub Actions: сборка debug APK и публикация artifact — [подтверждённый запуск](https://github.com/PseudoEF/HyprDroid/actions/runs/43699829017).
- [ ] Проверить установку APK, выбор HOME и возврат к другому лаунчеру на реальном устройстве.
- [ ] Проверить отображение и запуск приложений, свайпы и раскладки на устройстве, включая Pixel 9.

## Этап 1 — повседневное использование

- [ ] Список приложений с поиском, иконками и закреплением.
- [ ] Разные наборы плиток для рабочих пространств.
- [ ] Обновление списка при установке и удалении приложений.
- [ ] Понятные состояния ошибок запуска и пустого списка.
- [ ] Экран настроек и переход к системному выбору домашнего экрана.
- [ ] Сохранение пользовательских настроек и раскладки.
