# Техническое описание HyprDroid

## Назначение

HyprDroid — экспериментальный Android HOME-лаунчер с рабочими пространствами и раскладками собственных элементов интерфейса, вдохновлённый Hyprland. Долгосрочная цель — настройка оболочки через интерфейс и переносимые конфигурации. Пользовательская инструкция находится в [README](../README.md), состояние задач — в [ROADMAP](ROADMAP.md).

Минимальная версия Android — 10 (API 29), `compileSdk` и `targetSdk` — 35. Базовые функции не должны требовать root, Shizuku, ADB, разблокировки загрузчика или привилегированных разрешений.

## Текущая реализация

Приложение состоит из одного модуля `app`. `MainActivity` наследует `ComponentActivity` и объявлена в манифесте с действием `MAIN` и категориями `HOME` и `DEFAULT`. Интерфейс построен на Kotlin и Jetpack Compose с Material 3.

Сервис `LauncherApps` предоставляет список доступных launcher activities для текущего профиля. Собственный пакет исключается из списка, остальные элементы сортируются по подписи. Нажатие на плитку вызывает `startMainActivity`. Ошибки получения списка и запуска перехватываются, но отдельные сообщения об ошибках и пустом состоянии пока отсутствуют.

`HorizontalPager` отображает три рабочих пространства. Переключатель Grid/List меняет число колонок в `LazyVerticalGrid` с двух на одну. Все пространства используют общий список приложений; распределения плиток по пространствам пока нет.

Список приложений и выбор раскладки хранятся в состоянии Compose без постоянного хранилища. Иконки, поиск, обработка обновлений списка установленных приложений и пользовательские настройки пока не реализованы. Интерфейс имеет заданную в коде тёмную цветовую схему.

В репозитории есть Gradle Wrapper и workflow GitHub Actions для debug APK. Сборка и публикация artifact подтверждены [запуском для коммита 64d83e1](https://github.com/PseudoEF/HyprDroid/actions/runs/43699829017). Это не подтверждает установку или корректность работы на конкретном устройстве. Версии инструментов перечислены в [BUILD](BUILD.md).

## Планируемые компоненты

- Список приложений с поиском, иконками и закреплением.
- Независимые наборы плиток для рабочих пространств.
- Механизм раскладок grid, columns и master-stack для компонентов оболочки.
- Поддержка Android-виджетов через `AppWidgetHost`.
- Экран настроек и постоянное хранение параметров; рассматривается DataStore.
- Версионированные конфигурации TOML: импорт, экспорт, валидация, предпросмотр и откат.
- Позднее — импорт конфигураций из GitHub и ZIP, каталог тем.

Эти компоненты пока не реализованы. Для MVP не предполагается обязательный удалённый сервер.

## Ограничения платформы

Обычный лаунчер не может произвольно перемещать, изменять размеры или встраивать окна любых сторонних приложений без привилегированных Android window API. Управляемые раскладки относятся к собственным плиткам, виджетам и другим компонентам HyprDroid.

Системные режимы split-screen/freeform могут исследоваться отдельно с учётом версии Android и производителя устройства. Их универсальная доступность не гарантируется и не является критерием MVP.

Приложение должно сохранять стандартный способ смены HOME-лаунчера через настройки Android. Отдельной кнопки перехода к этим настройкам в текущем интерфейсе нет.

## Требования к будущему импорту конфигураций

Конфигурации являются данными: выполнение скриптов и произвольного кода запрещено. Импорт должен проверять версию схемы и содержимое, показывать предпросмотр и позволять откат к рабочей конфигурации. Для архивов необходимы ограничения размера и защита от небезопасных путей извлечения. Эти требования описывают будущую реализацию, а не существующую функцию.

## Критерии MVP

- APK устанавливается на поддерживаемое устройство и доступен в выборе домашнего экрана.
- Пользователь видит и запускает доступные приложения, переключает рабочие пространства свайпами.
- Пользователь импортирует валидный TOML-конфиг с темой и раскладкой, видит предпросмотр и может отменить применение.
- Некорректный импорт не лишает пользователя рабочего домашнего экрана.
- Пользователь может вернуться к другому лаунчеру через настройки Android.

MVP пока не завершён. Root-модули, собственная прошивка, управление окнами чужих приложений, маркетплейс с аккаунтами и выполнение сторонних скриптов не входят в его объём. Лицензия проекта пока не выбрана.
