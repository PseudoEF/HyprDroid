# HyprDroid — описание проекта

## Идея
HyprDroid — Android-лаунчер, вдохновлённый Hyprland. Его главная ценность — не копирование Linux-интерфейса, а **гибкая кастомизация**, тайлинговые рабочие пространства, жесты и возможность обмениваться конфигурациями (dots) через файлы и GitHub.

## Целевая аудитория
Любители кастомизации Android, пользователи Linux/Hyprland, энтузиасты минималистичных интерфейсов. Вход должен быть простым: установить APK, выбрать домашний экран, применить готовую тему.

## Непереговорные требования
- Без root, Shizuku, ADB, разблокировки загрузчика и специальных разрешений для базовой работы.
- Установка как обычного HOME-лаунчера на поддерживаемых версиях Android.
- Визуальные настройки доступны через UI и через экспортируемый конфиг.
- Возможность вернуться к стандартному лаунчеру через настройки Android.
- Безопасный импорт конфигов, предпросмотр, откат.
- Открытый исходный код (лицензию выбрать перед публикацией).

## Важное ограничение Android
Обычный лаунчер **не может произвольно перемещать, менять размеры или встраивать окна любых сторонних приложений**. Точно контролируемый тайлинг относится к собственным плиткам, виджетам и компонентам оболочки. Системный split-screen/freeform можно исследовать как отдельную экспериментальную интеграцию, без обещаний универсальной поддержки.

## Целевые функции
1. Рабочие пространства с переключением свайпами.
2. Tiling layouts: grid, master-stack, columns (сначала для элементов лаунчера).
3. App drawer, запуск приложений, поиск.
4. Системные Android-виджеты через AppWidgetHost.
5. Настройка отступов, скруглений, цветов, шрифтов, анимаций и панелей.
6. Dotfiles: TOML, import/export, проверка схемы, preview, rollback.
7. Импорт из GitHub URL / ZIP (позже), каталог тем (ещё позже).
8. Хороший UX на небольшом сенсорном экране, без клавиатуры/мыши.

## Технологии
Kotlin, Jetpack Compose, Android SDK, Gradle, GitHub Actions. Хранение настроек: DataStore (план). Формат конфигов: TOML (план). Никакого удалённого сервера для MVP.

## Что уже есть в стартовом репозитории
Минимальный HOME-лаунчер: список доступных launcher activities, запуск приложений, 3 перелистываемых рабочих пространства и переключатель Grid/List. Это **не** полноценный оконный тайлинг и пока **не** реализует dotfiles. Отображение приложений повторяется на всех рабочих пространствах; распределение по workspace — отдельная будущая задача.

## Критерии MVP
APK устанавливается на телефон, появляется в выборе домашнего экрана, показывает и запускает приложения, поддерживает свайпы между рабочими пространствами, импортирует безопасный TOML-конфиг с темой и раскладкой, восстанавливается после некорректного импорта.

## Не входит в MVP
Root-модули, собственная прошивка, управление окнами чужих приложений, маркетплейс с аккаунтами, выполнение сторонних скриптов.
