# Жесты панелей и порядок dock

## Панели

«Настройки панелей» → сторона → «Жесты»:

- **Swipe only** — значение по умолчанию, в том числе при чтении старых конфигураций. Одиночное касание маркера не открывает панель.
- **Tap + Swipe** — открытие также коротким касанием свободной зоны. В Home кнопки/иконки сохраняют приоритет.
- **Длина свайпа** — 24–96 dp, по умолчанию 48 dp. Требуются движение внутрь и явное горизонтальное направление; вертикальные, короткие, обратные и отменённые жесты не открывают панель.

Сохраните черновик панели. Настройки сторон независимы; ширина зоны, маркер, отступ и положение остаются прежними. Доступ через меню Home сохраняется для доступности.

В Home обычные касания дочерних кнопок не перехватываются. В Global Overlay Android направляет начавшийся внутри маленького окна зоны touch-поток этому окну: Swipe only не может передать такой тап приложению под ним. За границами окна касания свободны. Для кнопок соседнего приложения уменьшите ширину зоны или измените её положение; при конфликте с системным Back увеличьте отступ. Сквозного перенаправления ввода, Accessibility-перехвата или полноэкранного ловца касаний нет.

Панели сохраняются в схеме **v4**. v1–v3 читаются с Swipe only / 48 dp, без потери модулей, widget ID, размеров или порядка. Новая схема записывается только при явном изменении. Старые APK, не знающие v4, не поддерживают downgrade после сохранения; обновляйте поверх совместимым подписанным APK.

## Dock

На Home удерживайте закреплённую иконку и перетащите на соседнюю. Активная иконка выделяется; соседние элементы плавно меняют позиции. Отпускание сохраняет относительное перемещение; отмена оставляет прежний порядок. Автоскрытие dock приостанавливается во время drag. Обычный тап запускает приложение.

Меню Home → **«Настроить dock»** доступно также при пустом/скрытом dock. Здесь можно добавить приложения с поиском, убрать закрепление, переставить кнопками «Раньше/Позже». Лимит прежний — четыре приложения; кнопка app drawer в него не входит. Добавление/удаление также остаётся в контекстных действиях приложений в drawer и workspace. На самом dock удержание теперь предназначено для drag, альтернативные действия доступны в редакторе и через accessibility actions.

Порядок хранится в отдельном документе `favorites_order` v1 внутри прежнего shell DataStore. Набор `favorites` остаётся источником закреплений. У старого набора не было сохранённого порядка; до первой записи используется стабильная сортировка по компоненту. После записи применяется пользовательский порядок, а не сортировка по названиям. Пакетное удаление очищает только связанные закрепления; поздний drop не возвращает удалённую иконку. Неизвестный формат не сбрасывается и не перезаписывается.

## Полировка и проверки

Home, drawer, панели и настройки используют прежнюю тему с согласованными контрастами кнопок. Общий Slider сохраняет дробное положение во время drag, пока целые значения настроек или системные наблюдатели обновляются. Quick Settings применяет значение при отпускании; ограничения Android и оценка яркости остаются видимыми в статусе, подробности шкалы свёрнуты. Пояснения конфликтов жестов доступны отдельным раскрываемым блоком.

Тесты покрывают миграцию/перезапуск порядка, конкурентное добавление/перенос, удаление пакета, неизвестные данные, tap/swipe/порог, drag/cancel, добавление/удаление через UI и независимость Clean/Classic. Отдельные seed/verify проверяют настройки жестов, dock, GIF и RemoteViews после force-stop и установки поверх. Результаты CI и фактический Android API фиксируются в [BUILD](BUILD.md); физический Pixel9 учитывается отдельно.
